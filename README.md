# Autoévaluation Big Data — Chapitre 2, partie 1

Site statique d’autoévaluation portant sur le support jusqu’à la slide 34 : calcul distribué, scale-up/scale-out, Hadoop, HDFS, blocs, réplication, NameNode/DataNodes, tolérance aux pannes, haute disponibilité, lecture/écriture, data locality, configuration et commandes HDFS.

## Contenu

- `index.html` — structure du site
- `style.css` — design responsive premium
- `quiz.js` — 30 questions, correction immédiate, bilan et révision ciblée
- `assets/` — illustrations HD avec fond transparent

## Utilisation locale

Ouvrez simplement `index.html` dans un navigateur récent.

## Déploiement sur GitHub Pages

1. Créez un nouveau dépôt GitHub.
2. Déposez **tout le contenu de ce dossier à la racine du dépôt** (`index.html`, `style.css`, `quiz.js`, `assets/`).
3. Dans le dépôt, ouvrez **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Choisissez la branche `main` et le dossier `/ (root)`.
6. Cliquez sur **Save**.
7. GitHub affichera l’adresse du site après le déploiement.

Aucun backend, aucune base de données et aucune dépendance externe ne sont nécessaires.
